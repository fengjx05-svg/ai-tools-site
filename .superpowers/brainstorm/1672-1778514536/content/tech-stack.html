技术栈 & 项目结构

符合你的要求：Next.js + TypeScript + Tailwind + MDX + Vercel

技术选型

框架：Next.js 15 (App Router)

语言：TypeScript

样式：Tailwind CSS

内容：MDX 文件（本地 markdown）

渲染：SSG (静态生成) + ISR (增量更新)

部署：GitHub → Vercel（免费）

分析：Vercel Analytics + Google Search Console

广告：Google AdSense

为什么不用 CMS？
新手站点内容量还不大，MDX 文件写完即部署，免数据库、免后端、加载快、Google 友好。以后量大再迁到 Headless CMS。

为什么选这个方案

优势

  • MDX 直接写内容，本地编辑 → Git push → 自动部署
  • 静态页面加载快，Google Lighthouse 高分
  • 零服务器成本，Vercel 免费额度够用
  • TypeScript 保证代码质量

注意

  • 内容多了以后 MDX 管理不如 CMS 方便
  • 没有后台管理界面，编辑靠代码编辑器
  • 后期内容量大可迁移到 Contentlayer 或 CMS
